## 概要 (TL;DR)

Hugging Faceは、汎用エージェントプロジェクト「Jack of All Trades (JAT)」を発表しました。これは、DeepMindのGatoのオープンな再現を目指し、単一のTransformerモデルでビデオゲーム、ロボット制御、ナビゲーション、NLP、CVタスクなど、多様なタスクを実行できるエージェントです。JATは、専門家RLエージェント、初の汎用エージェント訓練用データセット「JATデータセット」、および「JATモデル」を公開。RLタスクにおいて専門家レベルの性能を模倣し、特に観察予測を補助タスクとして適切に組み込むことで学習効率が向上する可能性を示しました。

## 重要ポイント

*   **汎用エージェントJATの発表**: 多様なタスクを単一のTransformerモデルで実行可能な「Jack of All Trades (JAT)」エージェントを公開。
*   **Gatoのオープンな再現**: DeepMindのGatoのオープンな再現プロジェクトとして開始され、シーケンシャルデータと連続値処理において改善を導入。
*   **主要成果物の公開**:
    *   多数の専門家RLエージェント。
    *   初の汎用エージェント訓練用データセット「JATデータセット」（数十万の専門家軌跡とテキストデータを含む）。
    *   Transformerベースの「JATモデル」。
*   **多様なタスクでの高性能**: Atari、BabyAI、Meta-World、MuJoCoなどのRLドメインで専門家の平均65.8%の性能を達成。
*   **観察予測の利点**: 補助タスクとして観察予測を適切に（重みパラメータκ=0.005付近で）組み込むことで、エージェントの学習効率が向上することを発見。

## 詳細レポート（What happened/背景/影響/関係者/データ）

**What happened:**
Hugging Faceは、汎用エージェント「Jack of All Trades (JAT)」プロジェクトを発表しました。これは、単一のTransformerモデルがビジョン・言語タスクと意思決定タスクの両方を実行できることを目指し、多様な環境で訓練された専門家RLエージェント、それらから収集された大規模なJATデータセット、およびJATモデルを公開しました。

**背景:**
プロジェクトは、DeepMindのGato（Reed et al., 2022）のオープンな再現として始まりました。Gatoが提案した、ビジョン・言語と意思決定タスクを両方こなせるTransformerの訓練を目指し、まずGatoのデータセットのオープン版を構築。その後、シーケンシャルデータと連続値の処理においてGatoに対するいくつかの改善を導入したマルチモーダルTransformerモデルを訓練しました。

**影響:**
JATモデルは、ビデオゲームのプレイ、ロボット制御、シンプルなナビゲーション環境でのコマンド理解と実行など、幅広いタスクをこなすことができます。RLタスクでは専門家レベルの性能を模倣し、単一ネットワークで複数のドメインに対応できる汎用性を示しました。また、観察予測を補助タスクとして適切に組み込むことで、エージェントの学習効率が向上する可能性を発見し、汎用エージェント設計における補助目的の価値を強調しました。

**関係者:**
*   **プロジェクト発表元**: Hugging Face
*   **論文著者**: Quentin Gallouédec, Edward Beeching, Clément Romac, Emmanuel Dellandréa
*   **技術基盤**: EleutherAIのGPT-Neo実装

**データ:**
*   **専門家ポリシー**: Atari、BabyAI、Meta-World、MuJoCoなど、性質と難易度が異なる幅広い環境でSOTA性能を達成したRLエージェントが訓練され、公開されています。
*   **JATデータセット**: 初の汎用エージェント訓練用データセットとして公開されました。
    *   上記専門家エージェントが収集した数十万の専門家軌跡（expert trajectories）を含みます。
    *   RLデータに加え、Wikipedia、Oscar、OK-VQA、Conceptual-Captionsなどのテキストデータセットも含まれ、ユニークなユーザーインターフェースを可能にします。
    *   Hugging Face Hubから簡単にロード可能です（例: `datasets.load_dataset("jat-project/jat-dataset", "metaworld-assembly")`）。

**JATエージェントアーキテクチャ:**
*   **基盤**: EleutherAIのGPT-Neo実装に基づくTransformer。
*   **埋め込みメカニズム**: シーケンシャルな意思決定タスクを本質的に処理するために設計され、観測埋め込み、行動埋め込み、対応する報酬を交互に配置します。
*   **エンコーディング**:
    *   画像データ（Atariなど）にはCNNを使用。
    *   連続ベクトルには線形層を使用。
    *   離散値には線形射影層を使用。
    *   テキストデータにはGPT-2トークン化戦略、画像にはViT型エンコーダも使用。
*   **予測**: 観測を1タイムステップずらした因果予測により、エージェントは過去の全ての観測と行動から次の行動を予測します。
*   **損失計算**: 各モダリティ（画像・連続値はMSE損失、離散値は交差エントロピー損失）で個別に損失を計算し、最終損失はシーケンス要素ごとの損失の平均です。

**実験と結果:**
JATは157の訓練タスクで評価され、各RLドメインにおける専門家に対する集計スコアは以下の通りです。

| ドメイン      | 専門家に対する平均性能 | 人間に対する平均性能 (Atariのみ) | 特記事項                                      |
| :------------ | :--------------------- | :------------------------------- | :-------------------------------------------- |
| **全体平均**  | 65.8%                  | -                                | 4つのドメイン全体での平均性能                 |
| **Atari 57**  | 14.1%                  | 37.6%                            | 21ゲームで人間性能を超過                      |
| **BabyAI**    | 99.0%                  | -                                | 1タスクのみ専門家の50%を下回る                |
| **Meta-World**| 65.5%                  | -                                | -                                             |
| **MuJoCo**    | 84.8%                  | -                                | -                                             |

*   **単一ネットワークの強み**: JATは、これら全てのドメインで単一のネットワークを使用してこの性能を達成しています。
*   **テキストタスク**: 初歩的な能力を示します。
*   **観察予測の利点**: 観測損失と行動損失を組み合わせた損失関数（重みパラメータκ）を用いた実験で、κ=0.005付近の「スイートスポット」において、観察予測を学習することがエージェントの学習効率を実際に向上させることが判明しました。これは、補助目的が学習効率改善に寄与する可能性を示唆しています。

## リスクと課題

*   **データ改善の必要性**: JATデータセットは初期段階であり、各環境につき1つの専門家エージェントからの軌跡であるため、バイアスが生じる可能性があります。より多くのデータ収集と専門家エージェントの訓練が望まれます。
*   **オフラインRLの活用**: 現在のJATエージェントは基本的なBehavioral Cloningで訓練されており、準最適軌跡の活用や専門家を超える性能達成ができません。オフラインRLの導入により、性能向上が期待されます。
*   **マルチタスクサンプリング戦略の最適化**: 現在はタスクから均一にデータをサンプリングしていますが、最も困難なタスクに焦点を当てるよう動的にサンプリングレートを調整することで、学習プロセスを加速し、大幅な性能向上を達成できる可能性があります。

## 今後の見通し/アクション

JATプロジェクトは、汎用エージェント研究の新たな方向性を開拓したと見なされています。今後の研究として、以下の点が挙げられています。

*   **データ品質の向上**: より多様な専門家エージェントからのデータ収集と、データセットの拡充。
*   **オフラインRLの導入**: Behavioral CloningからオフラインRLへの移行により、エージェントの性能を向上させる。
*   **スマートなマルチタスクサンプリング戦略の開発**: 学習効率を最大化するために、タスクの難易度に応じてサンプリングレートを動的に調整する戦略を模索する。

これらの取り組みを通じて、より汎用性が高く、有能なAIシステムの開発に貢献することが期待されています。
