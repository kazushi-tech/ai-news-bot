## 概要 (TL;DR)

Hugging Faceは、AIモデルの安全性とセキュリティ評価を標準化する新イニシアチブ「RiskRubric.ai」を発表しました。Cloud Security AllianceとNoma Securityが主導し、透明性、信頼性、セキュリティ、プライバシー、安全性、評判の6つの柱でモデルを評価します。これにより、開発者はモデルの脆弱性を特定し、ユーザーは信頼できるモデルを選択できるようになります。2025年9月時点の評価では、多くのモデルが安全な一方で、中程度の保護レベルのモデルが懸念されており、セキュリティ強化が安全性向上に直結することが示されています。

## 重要ポイント

*   **AIモデルの標準化されたリスク評価**: RiskRubric.aiは、AIモデルのリスクを6つの柱（透明性、信頼性、セキュリティ、プライバシー、安全性、評判）で評価し、0-100のスコアとA-Fのレターグレードを提供します。
*   **オープンモデルエコシステムの信頼構築**: 50万以上のモデルが存在するHugging Faceハブにおいて、モデル選択の指針と安全性・セキュリティの透明性を提供します。
*   **評価結果の傾向**: 多くのモデルは安全な範囲にあるものの、中程度の保護レベル（C/Dレンジ）のモデルが存在し、これらが主要な懸念領域となっています。
*   **セキュリティと安全性の相関**: コアセキュリティ制御の強化（例：プロンプトインジェクション防御）は、有害な出力防止（安全性）にも直接的に寄与することが判明しました。
*   **透明性とガードレールのバランス**: 厳格な保護策がユーザーに対する透明性を損なう可能性があり、信頼維持のためには説明的な拒否や監査可能性との両立が重要です。

## 詳細レポート

### What happened

Hugging Faceは、Cloud Security AllianceとNoma Securityが主導し、Haize LabsとHarmonic Securityが貢献する新しいイニシアチブ「RiskRubric.ai」を発表しました。これは、AIモデルのリスクを標準化された方法で評価し、その結果を公開することで、AIモデルエコシステム全体の安全性と信頼性を向上させることを目的としています。

### 背景

Hugging Faceハブには50万以上のAIモデルが存在しますが、ユーザーがセキュリティ、プライバシー、潜在的な故障モードといった側面から最適なモデルを選択するための体系的な評価方法が不足していました。AIモデルの能力向上と普及加速に伴い、AIの安全性とセキュリティ報告における迅速な進歩が喫緊の課題となっていました。

### 影響

RiskRubric.aiは、開発者が自身のモデルの弱点を特定し、改善するための具体的な指針を提供します。また、組織は特定の要件（例：医療用途でのプライバシー保証）に基づいてモデルをフィルタリングし、より情報に基づいたデプロイメント決定を下せるようになります。評価結果が公開・標準化されることで、コミュニティ全体がモデルの安全性向上に協力し、透明な改善の好循環を生み出すことが期待されます。

### 関係者

*   **主導**: Cloud Security Alliance, Noma Security
*   **貢献**: Haize Labs, Harmonic Security

### データ

RiskRubric.aiは、以下の6つの柱でモデルを評価します。各評価はNoma Securityの自動化機能を利用し、1,000以上の信頼性テスト、200以上の敵対的セキュリティプローブ、自動コードスキャン、ドキュメントレビュー、プライバシー評価、安全性評価などが行われます。

1.  **透明性**: モデルの動作、トレーニングデータ、メソッドの明確さ。
2.  **信頼性**: 一貫性、エッジケース処理、予測可能性。
3.  **セキュリティ**: ジェイルブレイク、プロンプトインジェクション、コードの脆弱性。
4.  **プライバシー**: データ保持、漏洩リスク、個人情報保護。
5.  **安全性**: 有害な出力の防止、倫理的側面。
6.  **評判**: コミュニティからの評価、開発者の信頼性。

**2025年9月時点の評価結果の傾向:**

*   **リスク分布の二極化**:
    *   総リスクスコアは47～94の範囲で、中央値は81（100点満点）。
    *   54%のモデルがAまたはBレベルの「より安全な」範囲に集中。
    *   一方で、50～67のC/Dレンジに位置するモデルは「中程度から低い全体的な保護」を提供し、セキュリティギャップが実質的な懸念領域。
    *   「平均的なモデルが安全だと思い込まないこと」が強調されています。
*   **安全性リスクとセキュリティ姿勢の相関**:
    *   安全性・社会的柱（有害出力防止など）はモデル間で最も大きなばらつきを示します。
    *   セキュリティ強化（プロンプトインジェクション防御、ポリシー適用）に投資したモデルは、安全性スコアも向上する傾向があります。
    *   「コアセキュリティ制御の強化は、ジェイルブレイク防止だけでなく、下流の損害も直接的に軽減する」と結論付けられています。
*   **ガードレールと透明性のトレードオフ**:
    *   厳格な保護策（ガードレール）は、説明なしの拒否などにより、エンドユーザーに対するモデルの透明性を損なう可能性があります。
    *   これにより、ユーザーはシステムを「不透明」と感じ、信頼ギャップが生じる可能性があります。

## 引用（Notable quotes）

*   「平均的なモデルが安全だと思い込まないこと。弱いモデルの裾野は現実のものであり、攻撃者はそこに焦点を当てるでしょう。」
*   「コアセキュリティ制御の強化は、ジェイルブレイク防止だけでなく、下流の損害も直接的に軽減します！」
*   「セキュリティは信頼を犠牲にしてはならない。両者のバランスを取るためには、強力な保護策と説明的な拒否、出所情報、監査可能性を組み合わせるべきです。」

## リスクと課題

*   **中程度の保護レベルのモデル**: 多くのモデルが安全な一方で、中程度の保護レベル（C/Dレンジ）のモデルが多数存在し、これらが攻撃者の主要な標的となるリスクがあります。
*   **透明性の低下**: 厳格なセキュリティガードレールが、モデルの動作の透明性を損ない、ユーザーの信頼を低下させる可能性があります。セキュリティとユーザーの理解・信頼のバランスを取ることが課題です。

## 今後の見通し/アクション

RiskRubric.aiは、AIモデルの安全性評価を公開・標準化することで、コミュニティ全体でのモデル安全性向上を目指します。開発者は自身のモデルの強化点を確認し、コミュニティは修正やより安全なファインチューニング版の貢献を通じて、透明な改善の好循環を生み出すことが期待されます。
Hugging Faceは、モデルの評価提出（または既存モデルの提案）や、評価方法およびスコアリングフレームワークに関するフィードバックを広く募集しています。
