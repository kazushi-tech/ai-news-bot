# AIブームと投資過熱：ドットコム・バブルとの比較

## TL;DR
AIブームの本格化に伴い、1990年代後半のドットコム・バブルに匹敵する投資過熱への警鐘が鳴らされています。当時のドットコム・バブルは、最終的に壮絶な崩壊を迎えました。現在のAI分野における熱狂的な投資状況にも、同様のリスクが指摘されています。

## Key points
*   人工知能（AI）ブームが本格化している。
*   AIブームの勢いと並行して、投資過熱への警鐘が鳴らされている。
*   現在の投資過熱は、1990年代後半のドットコム・バブルに匹敵すると指摘されている。
*   ドットコム・バブルは、当時の熱狂が壮絶な崩壊で幕を閉じた歴史がある。
