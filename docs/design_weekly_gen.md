# Weekly Auto-Generation Logic

## 1. Input Collection

- **Target Range:** 1 week (Monday to Sunday, or last 7 days). Specifiable via CLI args.
- **Source:** `news/ai/*.md` (and `news/*.md` for backward compatibility).
- **Extraction:**
  - Parse Daily Markdown tables and Details sections.
  - Extract: Title, URL, TLDR (One-line summary), Bullets, Tags, Reliability, Why it matters.
  - Filter: Exclude low reliability or irrelevant items if needed.

## 2. Gemini Prompting

- **Role:** AI Tech News Editor.
- **Context:** List of ~30-50 articles from the week.
- **Task:** Synthesize a weekly report.
- **Output Format:**
  1.  **Overview:** 2-4 lines summarizing the week's biggest theme.
  2.  **Top 5 News:** Select 5 most impactful stories.
      - Title, link, concise summary, why it matters.
  3.  **Trends:** Identify 2-3 key trends/themes (e.g., "Small Models", "Regulation").
  4.  **Key Releases:** List major product/model releases.
  5.  **Appendix:** Full list of processed articles (can be generated by script, not LLM, to save tokens).

## 3. Output Generation

- **Template:** `_templates/weekly.md`
- **Filename:** `weekly/YYYY-Wnn.md`
- **Idempotency:** Overwrite existing file for the same week to ensure freshness and avoid duplicates.

## 4. Script Structure (`scripts/build_weekly.mjs`)

```javascript
import { collectDailiesInWeek } from './lib/index-utils.mjs';
import { callGemini } from './lib/gemini.mjs';

async function main() {
  const range = getWeekRange(argv.date);
  const dailies = await collectDailiesInWeek(range);
  const articles = extractArticles(dailies);

  const prompt = buildPrompt(articles);
  const report = await callGemini(prompt);

  const markdown = applyTemplate(report, articles);
  await saveWeekly(markdown);
}
```
